Molecules

    How to use
    • Drag an element from the table into the sandbox.
    • Drop it on an atom to bond it there.
    • Click an atom, then another atom, to bond them. Repeat for double/triple.
    • With an atom selected, click an element in the table to attach it.
    • Click a bond to cycle single → double → triple.
    • Drag atoms to move them. Right-click or Delete removes.

    Bonding uses common valences as an approximation; it ignores formal charges, coordinate bonds and ionic/metallic character. Dashed ring = unfilled valence.
